# WING runtime distillation promotion audit

The audit treats `distillation/` as evidence, not as a new global policy. `weekly_trace.jsonl` records four completed VOCAL weeks and one later business-choice stop. `SELFEXP_20260905_04` supplies the WING entry identity; no AGY or game run was invoked for this audit.

## Decisions

- **VOCAL normal-week loop — HOLD.** Four S1 weeks support a repeated run-local loop, but the proposed controls are fixed coordinates. The distillation does not prove fresh state, viewport, local anchor, bounds, TTL, and post-action verification at the authorization boundary. It must not become production-executable or a cross-season rule.
- **Interruption dual-channel detection — PROMOTE.** Two distinct runtime observations support SKIP-based support events (week 3) and no-SKIP communication dialogue (week 4). This promotes detection only; ambiguous/business-choice screens still stop.
- **BUSINESS_CHOICE dual-check-card detection — HOLD.** One concrete week-5 occurrence is recorded. It may produce `BUSINESS_CHOICE_DETECTED`, never `BUSINESS_CHOICE_RESOLVED`; default behavior remains STOP/taught-choice lookup.
- **Stable WING_HOME entry identity — PROMOTE.** SELFEXP_04 provides the matched entry into WING_HOME, and the distillation reports nine successful schedule entries across two sessions. This is page identity memory, not a click permission.
- **weeks_remaining - 1 — PROMOTE with scope.** Four sequential deltas support `ROOM_COMPLETION_EVIDENCE` for S1. It is not `ROOM_EFFECT_TRUTH` and cannot prove all VOCAL business effects.

## Controls

`CONTROLS_PRODUCTION_EXECUTABLE = NO`. Every fixed-coordinate control requires: fresh source state, valid viewport signature, in-bounds geometry, cheap local anchor/page identity, action TTL, and verified expected transition. “5/5 worked” is insufficient without these guards.

## Normal-week AGY status

`NORMAL_WEEK_NO_AGY = NOT_VALIDATED`. The distillation records zero AGY calls for the run, but the separate real-frame cheap HOME benchmark returned `UNKNOWN` (`AUDITION_BATTLE`, `home_state_not_confirmed`, season OCR failure), so an end-to-end no-AGY normal-week observation gate is not yet validated.

No Planner, Skill, bridge, runtime, or game state was modified. No production promotion was performed.
